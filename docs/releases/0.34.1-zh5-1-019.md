# DCSS 中文版 0.34.1-zh5-1-019

本次更新基于 DCSS 0.34.1，汇总 018 之后合入稳定线的 C++ 国际化和界面修复、D-1..D-7 术语统一、Wave 1–3 全库及文档润色与运行时消息覆盖一致性修正。上游内容基线不变。

- **C++ 国际化与界面显示修复**：
  - 修正面向玩家时的怪物对白所有格 `问 @foe,@「…」` 显示，支持窄终端下 Q 快捷动作菜单换行测量及状态栏按 CJK 宽度的折行（[#449](https://github.com/yutio8888/crawl-chn-ai-test/pull/449)）；
  - 修复 `Water status` 地形判断、`Contam status` 发光状态、黏着火焰三档状态上下文、动作页脚标点及拾取/偷窃金币的 `（获得了%d）` 后缀显示（[#451](https://github.com/yutio8888/crawl-chn-ai-test/pull/451)、[#452](https://github.com/yutio8888/crawl-chn-ai-test/pull/452)、[#455](https://github.com/yutio8888/crawl-chn-ai-test/pull/455)）；
  - 修正 `get_gizmo_name` 样式 2–4 的中文词间空格（保留英文 TextDB 缺省回退词间空格）、祭坛跨层寻路首字母热键查找，以及 Xom 血喷泉单复数消息模板（[#466](https://github.com/yutio8888/crawl-chn-ai-test/pull/466)）。
- **D-1..D-7 术语对齐与随机书名去重**：统一 `flail` 为“链枷”、七项变异裸键、全局 `contamination` 为“魔法污染”（D-C-126）、`quiver` 动作为“快捷动作”（D-C-127）、`cleave` 为“顺劈”、`Fire+`/`Fire++` 为“着火+`/`着火++”及 Vehumet 能力射程描述；简化 `randbook.txt` 学派形容词词干与等级书名模板以消除重复的“的”（[#457](https://github.com/yutio8888/crawl-chn-ai-test/pull/457)）。
- **高/中低频全库文本与 Wave 1–3 质量润色**：
  - 完成高 ROI 界面/引导/机制/物品/怪物条目及中低频与可裁决暂缓条目（含 *Uti vår hage*、引文、武器歌、神祇人称及移除英文原文未陈述的额外机制）的全面润色（[#459](https://github.com/yutio8888/crawl-chn-ai-test/pull/459)、[#461](https://github.com/yutio8888/crawl-chn-ai-test/pull/461)）；
  - Wave 1–3 修正 `help.txt` 拾取快捷键对调、17 份 `descript/zh/` 描述与数据库文本、补全 `gizmo.txt` 词库（含 `bogo` → `波戈`）、同步 3 条 `CANDIDATE` 怪物施法运行时覆盖与 `zh/monspell.txt`，并将 `options_guide.txt` 中的“发射栏”全部对齐为“快捷动作”（[#463](https://github.com/yutio8888/crawl-chn-ai-test/pull/463)、[#466](https://github.com/yutio8888/crawl-chn-ai-test/pull/466)、[#467](https://github.com/yutio8888/crawl-chn-ai-test/pull/467)）。

## 下载哪个文件？

| 平台 | 文件名后缀 | 使用方法 |
| --- | --- | --- |
| Windows 图块版 | `tiles-win32.zip` | 解压后运行 `crawl.exe`。 |
| Windows ASCII／字符版 | `console-win32.zip` | 解压后运行 `crawl.exe`，地图以字符显示。请选用支持中文的终端字体。 |
| Linux x86_64 字符版 | `console-linux-x86_64.zip` | 解压后在 UTF-8 终端中进入目录，运行 `./crawl`；依赖见包内 `README-linux.txt`。 |
| macOS 图块版 | `tiles-macosx.dmg` | 打开 DMG，将应用复制出来后运行。 |
| Android | `android.apk` | 下载签名 APK 后按系统提示安装。 |

Windows 两种包均为 x86-64；`win32` 是沿用的文件名后缀。Android 正式 APK 包含 arm64-v8a、armeabi-v7a、x86、x86_64 四种 ABI。

字符版仍包含中文界面和游戏文本；“字符版”指地图的显示方式。Linux 包以 Ubuntu 22.04 x86_64 为构建基线，需要 ncurses、Lua 5.4、SQLite、zlib 及系统 C/C++ 运行库，不支持 ARM 或 32 位 Linux。

## 升级与首次启动

- 升级前请备份原有存档、战报和个人设置，建议解压到新目录后再迁移。此版本继续沿用 0.34.1 内容基线；请保留原包作为备份。
- 旧存档中已生成的随机书名、神器名与历史消息记录不迁移；新命名与翻译只作用于新显示或新生成的内容。
- 图块版随包附带中文字体；字符版使用终端字体，如出现方框或对齐异常，请检查 UTF-8 与中文等宽字体设置。
- macOS 应用采用 ad-hoc 签名，尚无 Apple Developer 签名或公证。若 Gatekeeper 拦截，请通过应用右键菜单选择“打开”，或前往“系统设置 → 隐私与安全性”选择“仍要打开”。核对下载校验值后，也可对已复制出的应用执行：

  ```sh
  xattr -dr com.apple.quarantine "Dungeon Crawl Stone Soup - Tiles.app"
  ```

## 下载校验与反馈

下载对应的游戏包和 `SHA256SUMS`，可运行 `sha256sum --ignore-missing -c SHA256SUMS` 核对已下载的文件。macOS 可用 `shasum -a 256 <文件名>`，Windows PowerShell 可用 `Get-FileHash <文件名> -Algorithm SHA256`。`RELEASE-MANIFEST.txt` 记录标签、源码提交及各包的摘要。
