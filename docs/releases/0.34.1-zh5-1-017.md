# DCSS 中文版 0.34.1-zh5-1-017

本次更新基于 DCSS 0.34.1，汇总 016 之后第 23–50 轮抽样检查（分层随机抽样、两位独立评审）和全文模式检索发现的翻译问题修复，并修复 WebTiles 服务器的资源缓存问题。上游内容基线不变。

- **术语决定**：torpor snail 改为“迟滞蜗牛”（D-C-117）；盐之荒原的两位神灵统一为“谢扎”与“萨格尔”，与法术“谢扎之舞”一致（D-C-118）。其他既有术语如极地漩涡、盖尔之加沃特、负重等级、杂音（Cacophony）在相关说明和消息中统一。（[#354](https://github.com/yutio8888/crawl-chn-ai-test/pull/354)、[#396](https://github.com/yutio8888/crawl-chn-ai-test/pull/396)、[#398](https://github.com/yutio8888/crawl-chn-ai-test/pull/398)、[#404](https://github.com/yutio8888/crawl-chn-ai-test/pull/404)、[#408](https://github.com/yutio8888/crawl-chn-ai-test/pull/408)）
- **怪物名称**：中文界面下怪物名前不再残留英文冠词 “a ”/“the ”（含少数带定冠词的独特怪物）。（[#386](https://github.com/yutio8888/crawl-chn-ai-test/pull/386)、[#388](https://github.com/yutio8888/crawl-chn-ai-test/pull/388)）
- **多余空格与格式**：教学提示中神名、怪物名两侧的多余空格；孢子、恐惧僵住、盾牌致盲等直接输出消息中名字后的多余空格；商店金币提示多出的空行。（[#396](https://github.com/yutio8888/crawl-chn-ai-test/pull/396)、[#404](https://github.com/yutio8888/crawl-chn-ai-test/pull/404)、[#406](https://github.com/yutio8888/crawl-chn-ai-test/pull/406)）
- **代词与语义**：怪物状态说明中把单个生物写成“它们”的问题；火山涌流、沼泽之光的生成与位置条件；沉默状态“许多生物”；丧尸与骷髅“不会自然回复生命值”；标枪对小体型种族“无法使用”；射术护甲品牌的“负重等级”；哈尔庇厄引文时序等。
- **扩大覆盖的文本类别**：抽样扩展到武器台词、喷泉与地形提示、怪物状态说明、卡牌、云、物品品牌、教学提示、FAQ 与怪物施法消息等类别，修正了其中的生硬直译、量词与叫声区分（嘎嘎、长鸣、窸窣）等问题。
- **WebTiles 服务器**：游戏资源 URL 改为随静态图集与索引文件变化，避免浏览器在服务器更新后把新程序与旧的缓存图集搭配，导致物品等图标显示为相邻图块。此项只影响 WebTiles 服务器部署：须更新 webserver 代码，并使用同一次构建产出的 `crawl` 与 `webserver/game_data/` 静态资源，部署后重启 WebTiles 服务器；本页的下载包不能替代服务器部署。（[#410](https://github.com/yutio8888/crawl-chn-ai-test/pull/410)）

## 下载哪个文件？

| 平台 | 文件名后缀 | 使用方法 |
| --- | --- | --- |
| Windows 图块版 | `tiles-win32.zip` | 解压后运行 `crawl.exe`。 |
| Windows ASCII／字符版 | `console-win32.zip` | 解压后运行 `crawl.exe`，地图以字符显示。请选用支持中文的终端字体。 |
| Linux x86_64 字符版 | `console-linux-x86_64.zip` | 解压后在 UTF-8 终端中进入目录，运行 `./crawl`；依赖见包内 `README-linux.txt`。 |
| macOS 图块版 | `tiles-macosx.dmg` | 打开 DMG，将应用复制出来后运行。 |
| Android | `android.apk` | 下载签名 APK 后按系统提示安装。 |

Windows 两种包均为 x86-64；`win32` 是沿用的文件名后缀。Android 正式 APK 包含 arm64-v8a、armeabi-v7a、x86、x86_64 四种 ABI。

字符版仍包含中文界面和游戏文本；“字符版”指地图的显示方式。Linux 包以 Ubuntu 22.04 x86_64 为构建基线，需要 ncurses、Lua 5.4、SQLite、zlib 及系统 C/C++ 运行库，不支持 ARM 或 32 位 Linux。

## 升级与首次启动

- 升级前请备份原有存档、战报和个人设置，建议解压到新目录后再迁移。此版本继续沿用 0.34.1 内容基线；请保留原包作为备份。
- 图块版随包附带中文字体；字符版使用终端字体，如出现方框或对齐异常，请检查 UTF-8 与中文等宽字体设置。
- macOS 应用采用 ad-hoc 签名，尚无 Apple Developer 签名或公证。若 Gatekeeper 拦截，请通过应用右键菜单选择“打开”，或前往“系统设置 → 隐私与安全性”选择“仍要打开”。核对下载校验值后，也可对已复制出的应用执行：

  ```sh
  xattr -dr com.apple.quarantine "Dungeon Crawl Stone Soup - Tiles.app"
  ```

## 下载校验与反馈

下载对应的游戏包和 `SHA256SUMS`，可运行 `sha256sum --ignore-missing -c SHA256SUMS` 核对已下载的文件。macOS 可用 `shasum -a 256 <文件名>`，Windows PowerShell 可用 `Get-FileHash <文件名> -Algorithm SHA256`。`RELEASE-MANIFEST.txt` 记录标签、源码提交及各包的摘要。
