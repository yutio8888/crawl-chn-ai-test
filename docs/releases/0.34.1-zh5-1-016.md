# DCSS 中文版 0.34.1-zh5-1-016

本次更新基于 DCSS 0.34.1，汇总 2026-11-12 至 13 日连续抽样检查（22 轮分层随机抽样、两位独立评审）和全文模式检索发现的翻译问题修复。上游内容基线不变。

- **术语统一（维护者决定 D-C-115/D-C-116）**：首饰类统称“首饰”；MP 资源统一为“法力”，普通魔法仍为“魔法”；角色报告；天堂风暴；赋格；深地巨魔；Horror 状态改为“惊骇”（Fear 仍为“恐惧”）；Vertigo 状态改为“头晕”（Dazed 仍为“眩晕”）；mutation 统一为“变异”；Hexes 学派与 trunk 一致改为“妖术系”。（[#302](https://github.com/yutio8888/crawl-chn-ai-test/pull/302)、[#320](https://github.com/yutio8888/crawl-chn-ai-test/pull/320)、[#332](https://github.com/yutio8888/crawl-chn-ai-test/pull/332)、[#336](https://github.com/yutio8888/crawl-chn-ai-test/pull/336)）
- **形态文本补全**：变形后在变异界面和说明中显示的各形态文本（蜂巢、蜘蛛、吸血鬼、狼人、斯芬克斯、卷轴、果冻，以及变形球引发的不稳定形态等）补齐中文，不再显示英文。（[#338](https://github.com/yutio8888/crawl-chn-ai-test/pull/338)）
- **衰竭机制**：drain/衰竭状态及其等级描述统一为“衰竭”，不再误写为“汲取生命”或“被吸取”；真正的生命吸取保持原样。（[#340](https://github.com/yutio8888/crawl-chn-ai-test/pull/340)）
- **消息拼接**：修复多处“的的”“被被”重复（怪物状态、玩家幻象与幽灵、万魔殿领主、湮灭猎犬嚎叫、网与蛛网等）；Xom 无害效果消息中的多余空格；Gozag 商人邀请句的空格、代词与店名；施法消息中把“掠过你”误写为“身后”；命中率与攻击延迟说明；淬毒飞镖不再显示为“中毒飞镖”。
- **漏译与英文泄漏**：能力界面说明、技能界面提示、查看菜单标题、地动（Upheaval）目标提示与碎裂术消息中的地形名、自定义镰刀名、隐形药水障碍名等处的英文或缺句。
- **语义与可读性**：大量法术、能力、怪物、物品与神明说明的语义更正和润色，例如 Bind Soul 的“至多轻伤”条件、招募使徒的涂抹授任、Foxfire 只在相邻格生成、Heal Other 的安抚条件、第一课楼梯说明、梦之羊名称统一、小丑派六种口味、怪物闪烁消息等。
- 修正本仓库此前引入的发条蜜蜂英文消息格式错误（"its's clockwork bee"）。（[#346](https://github.com/yutio8888/crawl-chn-ai-test/pull/346)）
- 发布流程：平台验收改为发布后由测试玩家进行（[#309](https://github.com/yutio8888/crawl-chn-ai-test/pull/309)）。

## 下载哪个文件？

| 平台 | 文件名后缀 | 使用方法 |
| --- | --- | --- |
| Windows 图块版 | `tiles-win32.zip` | 解压后运行 `crawl.exe`。 |
| Windows ASCII／字符版 | `console-win32.zip` | 解压后运行 `crawl.exe`，地图以字符显示。请选用支持中文的终端字体。 |
| Linux x86_64 字符版 | `console-linux-x86_64.zip` | 解压后在 UTF-8 终端中进入目录，运行 `./crawl`；依赖见包内 `README-linux.txt`。 |
| macOS 图块版 | `tiles-macosx.dmg` | 打开 DMG，将应用复制出来后运行。 |
| Android | `android.apk` | 下载签名 APK 后按系统提示安装。 |

Windows 两种包均为 x86-64；`win32` 是沿用的文件名后缀。Android 正式 APK 包含 arm64-v8a、armeabi-v7a、x86、x86_64 四种 ABI。

字符版仍包含中文界面和游戏文本；“字符版”指地图的显示方式。Linux 包以 Ubuntu 22.04 x86_64 为构建基线，需要 ncurses、Lua 5.4、SQLite、zlib 及系统 C/C++ 运行库，不支持 ARM 或 32 位 Linux。

## 升级与首次启动

- 升级前请备份原有存档、战报和个人设置，建议解压到新目录后再迁移。此版本继续沿用 0.34.1 内容基线；请保留原包作为备份。
- 图块版随包附带中文字体；字符版使用终端字体，如出现方框或对齐异常，请检查 UTF-8 与中文等宽字体设置。
- macOS 应用采用 ad-hoc 签名，尚无 Apple Developer 签名或公证。若 Gatekeeper 拦截，请通过应用右键菜单选择“打开”，或前往“系统设置 → 隐私与安全性”选择“仍要打开”。核对下载校验值后，也可对已复制出的应用执行：

  ```sh
  xattr -dr com.apple.quarantine "Dungeon Crawl Stone Soup - Tiles.app"
  ```

## 已知问题

- Q 快捷动作底栏在部分终端宽度下仍可能裁切。
- Justicar 再生触发时会多消耗一次随机数，因此旧版回放在该动作后可能出现差异。存档仍可读取。
- 部分动态消息（如菜单底栏分隔空格、个别独特怪物台词的目标拼接）尚无运行时证据，列为待玩家确认项。

## 下载校验与反馈

下载对应的游戏包和 `SHA256SUMS`，可运行 `sha256sum --ignore-missing -c SHA256SUMS` 核对已下载的文件。macOS 可用 `shasum -a 256 <文件名>`，Windows PowerShell 可用 `Get-FileHash <文件名> -Algorithm SHA256`。`RELEASE-MANIFEST.txt` 记录标签、源码提交及各包的摘要。
