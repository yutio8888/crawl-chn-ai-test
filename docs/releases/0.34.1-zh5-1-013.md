# DCSS 中文版 0.34.1-zh5-1-013

这次更新继续基于 DCSS 0.34.1，重点修复深入游玩中发现的中文搜索、帮助与提示问题，以及 Windows 字符版的中文显示和 Android 文本下载编码。

## 中文体验

- 补齐搜索排序、筛选、帮助与随身携带标签的中文显示，保留英文检索能力。（[#183](https://github.com/yutio8888/crawl-chn-ai-test/pull/183)）
- 补齐普通命令帮助的中文内容，改善装备警告、法力显示、楼梯、施法风险、护甲附魔与商店排序提示，并校正特伦斯的完整描述。（[#183](https://github.com/yutio8888/crawl-chn-ai-test/pull/183)）

## Windows 字符版与 Android

- Windows ASCII／字符版修复中文宽字符在屏幕缓冲中只占一列的问题，改善中英混排、覆盖重绘与行尾裁切的位置处理；实际终端与字体的视觉效果仍需人工验收。（[#186](https://github.com/yutio8888/crawl-chn-ai-test/pull/186)）
- Android 文本编辑页面下载导出文件时显式使用 UTF-8 编码。（[#189](https://github.com/yutio8888/crawl-chn-ai-test/pull/189)）

## 翻译术语调整

此节为候选占位，尚不计入本版已完成变化。用户已批准 lance 改为“骑枪”、统一 Wyrmbane 专名、中性单数代词改为“他”；相关工作由另一代理在稳定分支进行。若在打 tag 前合入，再根据实际提交补写本节；未合入的内容延期，不作为本版功能宣传。

## 下载哪个文件？

| 平台 | 文件名后缀 | 使用方法 |
| --- | --- | --- |
| Windows 图块版 | `tiles-win32.zip` | 解压后运行 `crawl.exe`。 |
| Windows ASCII／字符版 | `console-win32.zip` | 解压后运行 `crawl.exe`，地图以字符显示。请选用支持中文的终端字体。 |
| Linux x86_64 字符版 | `console-linux-x86_64.zip` | 解压后在 UTF-8 终端中进入目录，运行 `./crawl`；依赖见包内 `README-linux.txt`。 |
| macOS 图块版 | `tiles-macosx.dmg` | 打开 DMG，将应用复制出来后运行。 |
| Android | `android.apk` | 下载签名 APK 后按系统提示安装。 |

Windows 两种包均为 x86-64；`win32` 是沿用的文件名后缀。Android 正式 APK 包含 arm64-v8a、armeabi-v7a、x86、x86_64 四种 ABI。

字符版仍包含中文界面和游戏文本；“字符版”指地图的显示方式。Linux 包以 Ubuntu 22.04 x86_64 为构建基线，需要 ncurses、Lua 5.4、SQLite、zlib 及系统 C/C++ 运行库，不支持 ARM 或 32 位 Linux。

## 升级与首次启动

- 升级前请备份原有存档、战报和个人设置，建议解压到新目录后再迁移。此版本继续沿用 0.34.1 内容基线；请保留原包作为备份。
- 图块版随包附带中文字体；字符版使用终端字体，如出现方框或对齐异常，请检查 UTF-8 与中文等宽字体设置。
- macOS 应用采用 ad-hoc 签名，尚无 Apple Developer 签名或公证。若 Gatekeeper 拦截，请通过应用右键菜单选择“打开”，或前往“系统设置 → 隐私与安全性”选择“仍要打开”。核对下载校验值后，也可对已复制出的应用执行：

  ```sh
  xattr -dr com.apple.quarantine "Dungeon Crawl Stone Soup - Tiles.app"
  ```

## 下载校验与反馈

下载相应游戏包及 `SHA256SUMS`，可用 `sha256sum --ignore-missing -c SHA256SUMS` 校验已下载的文件；macOS 可用 `shasum -a 256 <文件名>`，Windows PowerShell 可用 `Get-FileHash <文件名> -Algorithm SHA256`，与清单对照。`RELEASE-MANIFEST.txt` 提供版本、源码提交与各包摘要。
