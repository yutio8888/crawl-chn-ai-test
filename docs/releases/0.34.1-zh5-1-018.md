# DCSS 中文版 0.34.1-zh5-1-018

本次更新基于 DCSS 0.34.1，汇总 017 之后合入稳定线的中文显示与文本修复，涵盖独特怪物与神器「」显示标记、固定与随机神器语序及命名池修正、随机书名与等级书名池补齐、近战战斗句式、未鉴定神赐标签、帮助键列对齐及 R51–R55 术语与措辞完善。上游内容基线不变。

- **特殊名称「」标记与神器语序**：中文界面为独特怪物、已知神器及专属随机名称外层添加「」显示标记（成对内层专名引号规范化为『』）；25 项固定神器中文全名调整为“「专名」类型”（D-C-120），随机神器统一为单层引号且强化等级与铭文在引号外，同时保持存档、原始查询与 WebTiles 过滤边界不变。（[#420](https://github.com/yutio8888/crawl-chn-ai-test/pull/420)、[#421](https://github.com/yutio8888/crawl-chn-ai-test/pull/421)、[#429](https://github.com/yutio8888/crawl-chn-ai-test/pull/429)）
- **随机神器命名与短写**：修正新生成中文随机神器的量词、修饰语、分支主题连接与首饰外观（D-C-121），并采用四项短写（飞翔、无尽的、百万、外科理发师），同时隔离随机书名共享的职业池。（[#427](https://github.com/yutio8888/crawl-chn-ai-test/pull/427)、[#432](https://github.com/yutio8888/crawl-chn-ai-test/pull/432)）
- **随机书名与等级书名池**：补齐 stable 线等级书名生成器查询键与魔法主题池，消除新书名混入英文与 `TOO MUCH RECURSION` 回退；修正“第 七 部分”等片段多余空格，统一独立语境“以及”与 Witchcraft（女巫法术）。（[#436](https://github.com/yutio8888/crawl-chn-ai-test/pull/436)、[#438](https://github.com/yutio8888/crawl-chn-ai-test/pull/438)）
- **战斗显示与神赐标签**：补全高伤害近战 28 条完整中文句式（消除“你 成碎片剁了…”片段）；近战未命中消息改用四档自然完整谓语；自动 `{god gift}` 在中文界面显示为 `{神赐}`（不改动自定义铭文与底层记录）。（[#435](https://github.com/yutio8888/crawl-chn-ai-test/pull/435)）
- **术语、提示与帮助对齐**：hellion 统一译为“地狱魔”（D-C-119），统一“杂音”与教程“命令面板”（[#417](https://github.com/yutio8888/crawl-chn-ai-test/pull/417)）；明确字母快捷键调整提示（[#424](https://github.com/yutio8888/crawl-chn-ai-test/pull/424)）；按 CJK 显示宽度对齐帮助键列与续行缩进，并修正 Brilliance 等状态/物品描述与 Slouch 描述“怪物”中心语（[#435](https://github.com/yutio8888/crawl-chn-ai-test/pull/435)、[#442](https://github.com/yutio8888/crawl-chn-ai-test/pull/442)）。

017 发布凭据归档见 [#414](https://github.com/yutio8888/crawl-chn-ai-test/pull/414)。

## 下载哪个文件？

| 平台 | 文件名后缀 | 使用方法 |
| --- | --- | --- |
| Windows 图块版 | `tiles-win32.zip` | 解压后运行 `crawl.exe`。 |
| Windows ASCII／字符版 | `console-win32.zip` | 解压后运行 `crawl.exe`，地图以字符显示。请选用支持中文的终端字体。 |
| Linux x86_64 字符版 | `console-linux-x86_64.zip` | 解压后在 UTF-8 终端中进入目录，运行 `./crawl`；依赖见包内 `README-linux.txt`。 |
| macOS 图块版 | `tiles-macosx.dmg` | 打开 DMG，将应用复制出来后运行。 |
| Android | `android.apk` | 下载签名 APK 后按系统提示安装。 |

Windows 两种包均为 x86-64；`win32` 是沿用的文件名后缀。Android 正式 APK 包含 arm64-v8a、armeabi-v7a、x86、x86_64 四种 ABI。

字符版仍包含中文界面和游戏文本；“字符版”指地图的显示方式。Linux 包以 Ubuntu 22.04 x86_64 为构建基线，需要 ncurses、Lua 5.4、SQLite、zlib 及系统 C/C++ 运行库，不支持 ARM 或 32 位 Linux。

## 升级与首次启动

- 升级前请备份原有存档、战报和个人设置，建议解压到新目录后再迁移。此版本继续沿用 0.34.1 内容基线；请保留原包作为备份。
- 旧存档中已生成的神器名、书名与历史消息记录不迁移；新命名规则与「」仅作用于新显示或新生成的内容。
- 中文显示名新增了「」标记；若个人 rc/Lua 脚本按显示名精确匹配独特怪物或神器，请按实际 API 返回值适配，内部查询名与自动拾取等原有键名维持不变。
- 图块版随包附带中文字体；字符版使用终端字体，如出现方框或对齐异常，请检查 UTF-8 与中文等宽字体设置。
- macOS 应用采用 ad-hoc 签名，尚无 Apple Developer 签名或公证。若 Gatekeeper 拦截，请通过应用右键菜单选择“打开”，或前往“系统设置 → 隐私与安全性”选择“仍要打开”。核对下载校验值后，也可对已复制出的应用执行：

  ```sh
  xattr -dr com.apple.quarantine "Dungeon Crawl Stone Soup - Tiles.app"
  ```

## 已知问题

- Q 快捷动作底栏在部分终端宽度下仍可能裁切。
- Justicar 再生触发时会多消耗一次随机数，因此旧版回放在该动作后可能出现差异。存档仍可读取。

## 下载校验与反馈

下载对应的游戏包和 `SHA256SUMS`，可运行 `sha256sum --ignore-missing -c SHA256SUMS` 核对已下载的文件。macOS 可用 `shasum -a 256 <文件名>`，Windows PowerShell 可用 `Get-FileHash <文件名> -Algorithm SHA256`。`RELEASE-MANIFEST.txt` 记录标签、源码提交及各包的摘要。
