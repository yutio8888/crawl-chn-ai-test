# DCSS 中文版 0.35-trunk-013 更新公告

各位地牢探险者好：

Dungeon Crawl Stone Soup 中文版现已发布开发分支预发布版 **0.35-trunk-013**。

> **特别提醒**：这是 trunk 预发布（开发线），**不是正式版**。稳定正式版 **0.34.1-zh5-1-017** 仍是推荐版本（Latest）。trunk 存档不能回到稳定版，两条线可并存安装，建议使用稳定版存档副本进行体验。

---

## 玩家可见亮点

### 1. 独特怪物与神器名称排版优化（新增「」）
中文模式下，独特怪物、固定神器与随机神器的名称在列表、观察与战斗日志中以「」标出：
- **战斗日志**：你击中了「西格蒙德」。（西格蒙德为独特怪物）
- **固定神器**：引号专名置于类型前，如 `+8 「屠龙者」骑枪`。
- **随机神器**：只保留一层引号，强化等级与铭文在引号外，如 `+9 「巨人杀手」长剑`。
- 随机神器修正了语法与数词量词，并精炼了长词组短写（如 `飞翔的乌斯卡亚`、`无尽的仆从`、`百万份最后通牒`、`外科理发师`）。

### 2. 战斗提示与新译名规范
- **近战未命中提示**：改为四档规范表述（完全没能击中 / 没能击中 / 差点就击中 / 只差毫厘就能击中），取代以往的“勉强未能击中”。
- **新译名**：hellion 改为“地狱魔”；统一“杂音”相关获得提示和状态名称；教程采用“命令面板”。
- **文本修润**：随机书名去掉“第 七 部分”等多余空格（现为“第七部分”）；调整了字母快捷键提示及部分描述文本；帮助页中跨层旅行、法术库与技能菜单的按键列对齐与标点已修正。

### 3. 上游游戏内容同步
- **新增称号**：新增形态修行称号、Xom 循环称号与变形术阶位称号。
- **机制与体验**：自动射击可穿过记忆中的隐形怪物；召回能力会检查伙伴是否已在身边；猎手与妖术射手初始装备、若干能力说明与机制调整。
- **地图与图块**：新增若干地图（含 Shoals 装饰地图与群岛地图）；更新内焰图标等图块。

## 升级与存档说明

- **旧存档机制**：旧存档中已生成的神器名、书名和已记录的消息历史不会改变；新的命名和「」只影响之后生成/显示的内容。
- **脚本适配**：中文显示名新增了「」；按 Lua 显示 API 返回值精确匹配的脚本可能需要适配，内部名称与查询/自动拾取等使用的名称维持原文——请按所用 API 的实际返回值检查，请勿盲目认定所有规则不受影响，也不要一律去掉引号。
