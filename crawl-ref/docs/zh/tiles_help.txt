注意：如果《Dungeon Crawl Stone Soup》的贴图版出现明显变慢或卡顿，请滚动
到本文末尾。


贴图版专用命令
--------------

你可以用多种方式与周围环境互动：既可以输入命令键，也可以使用鼠标。

画面右侧可点击的标签页区域尤其值得注意；借助它可以轻松打开物品栏、法术和
常用命令等内容。

根据屏幕分辨率，任何时刻可能会打开一个或多个面板；点击标签图标，可以临时
把物品栏视图换成另一类图块面板。

修改 settings 目录中 init.txt 的 tile_layout_priority 选项，可以自定义控制
面板的优先顺序。


移动
----

可以使用方向键、vi 键或数字小键盘移动。
（使用数字小键盘时，请分别尝试开启和关闭 Num Lock。）

数字小键盘： 7 8 9     vi 键：    y k u
               \|/                  \|/
              4-.-6                h-.-l
               /|\                  /|\
              1 2 3                b j n


按住 Shift 再按这些键，可以朝同一方向连续走若干步。

也可以用鼠标点击地图或小地图上的某处来移动。如果该格能从当前位置抵达，且
视野内没有敌对怪物，你会自动前往那里。如果视野内有敌对怪物，则每次只会走
一步。

要自动探索，可以输入 'o' 命令，也可以点击屏幕右侧命令面板中的对应图块。
与鼠标点击移动一样，只要视野内有敌对怪物，自动探索就不会启动。


获取信息
--------

在主地图或图块控制面板中，用鼠标右键点击任何地形、怪物或物品，会在单独的
画面中显示相应描述。

通常，只需把鼠标指针移到目标上，消息区也会显示相同描述，或显示其中能容纳
的部分。

同样，让鼠标在地形、怪物或物品上停留片刻，通常会显示列出可用命令的“工具
提示”。


攻击怪物
--------

使用移动键走向怪物，或用鼠标点击怪物，就能对其发动近战攻击。

要进行远程攻击（包括法术和魔杖），请把鼠标移到怪物上，等待工具提示出现。
也可以点击法术面板中的法术图块来施法，或点击物品栏面板中的弹药或魔杖来发射
弹药或激活魔杖。

命令面板中还有一个标为“自动战斗”（Autofight）的图块。点击后，如果身旁有
怪物，角色会对其发动近战攻击；如果身旁没有怪物，则会朝最近的怪物走一步。


使用物品
--------

使用物品最简便的方法，是在物品栏面板中点击它。鼠标悬停时的工具提示会说明
点击鼠标将执行什么操作，也会显示执行同一操作的对应命令键。
另一种方法是先在物品栏中选择物品（'i' 命令），再在动作提示中按适当的键。

要捡起地上的物品，可以在物品栏面板的地面区域逐一点击，也可以点击玩家图块，
打开一个可选择物品的菜单。使用后一种方法时，按 'Enter' 会确认选择并开始
拾取。

丢弃物品的方法类似：可以在物品栏面板中逐一点击物品，也可以输入 'd' 命令，
然后从菜单中选择物品。


与地牢互动
----------

同样，把鼠标移到主地图中的地形（例如楼梯或门）上，就会看到与其互动的方法。


角色状态
--------

用鼠标右键点击玩家图块，会显示角色总览画面，列出装备、抗性和属性。

要打开角色特定方面的详细画面，可以点击命令面板中的对应图块。


角色外观
--------

使用 '-' 命令打开人物编辑器，可以改变角色外观。按 'm' 可在几种模式之间
切换：装备（Equip）模式会根据你装备的物品动态更新外观；默认（Default）
模式使用基于角色种族和背景的图像；自定义（Custom）模式则允许完整自定义角色
外观的各个部分。用数字键切换自定义人物栏位，用方向键修改各个自定义图像的
不同部分。按 'Ctrl-S' 保存修改和选择。



如果出现明显变慢或卡顿……
------------------------

Crawl 使用 OpenGL 和 SDL 渲染图像。不过，要避免运行缓慢，它需要硬件加速。
如果使用 Windows，请务必更新显卡驱动程序。如果使用 Linux，请确保正在使用
DRI。

测试表明，旧至 i865 的显卡也能成功运行。遗憾的是，已知 i810 上运行速度很慢；
遇到这种情况，除了改用控制台版或更换机器之外，几乎没有其他办法。

可以尝试调整 settings 目录下 init.txt 中的下列选项，看看性能是否改善：

travel_delay = -1
    此设置会停止重绘，直到自动移动完成或中断。

tile_update_rate = 1000
    默认情况下，画面至少每 1000 毫秒重绘一次；如果你执行会改变显示内容的
    操作，重绘会更加频繁。可以尝试提高此值，但这可能导致画面更新耗时过长。

tile_runrest_rate = 17
    跑动和休息期间，画面每 17 毫秒重绘一次。如果 Crawl 在跑动或休息时很慢，
    请提高此数值。

tile_tooltip_ms = 0
    关闭工具提示后，每次需要绘制的内容会减少。

clear_map = false
    无需重绘视野外记忆中的怪物，可以减轻重绘流程的负担。

tile_window_width   = 1024
tile_window_height  = 768
    地图区域越大，每回合需要重绘的格子就越多。如果大屏幕显示的地图范围远超
    必需的 17x17 格，可以尝试指定较低的分辨率。
