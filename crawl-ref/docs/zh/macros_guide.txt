宏与按键映射
============

什么是宏和按键映射？简单来说：

命令宏把按键变成命令。
按键映射把按键变成其他按键。

说得详细一些：

大多数情况下，玩家可能需要的是命令宏。利用命令宏，可以让一个按键执行一串
命令（例如，用一次按键施放某个法术），同时不必担心该按键在提示界面中的作用
被打乱（例如，可以把数字或字母设成宏，而不必担心丢弃物品时该键也被替换）。

按键映射则用于修正键盘布局和行为问题（例如，可以把无法识别的数字小键盘序列
映射成对应数字，也可以调整外语键盘布局，让操作更顺手）。楼层地图、瞄准模式
和确认提示还各有一套专用按键映射，可以把映射限制在相应情境中。


如何创建宏和按键映射？
========================

最简单的方法是在游戏内设置：按 Ctrl-D 打开宏编辑器，再按 '~' 创建或编辑宏。
选择触发宏的按键，并输入命令序列。Ctrl-E 也能打开快速宏编辑器。对于某些按键
（或组合键），Crawl 会显示一个奇怪的数字（例如回车键显示为 \{13}）。这些数字
是某些非字母数字键的键码，在不同系统上可能有所不同。

默认情况下，Crawl 已为大多数大小写字母和数字键分配了功能。你当然也可以重新
映射这些按键，但最好先从当前未使用的按键开始，例如 Ins，也可以与 Ctrl、Shift
或两者组合使用。功能键可能已有绑定：例如 F1 会打开游戏菜单。在某些系统上，
还可以加入 Alt（Meta）键。

按键映射也在同一个编辑器中定义。按 '!' 可在宏和默认、菜单、楼层地图、瞄准、
确认等按键映射情境之间切换，再按 '~' 创建或编辑映射。

定义宏或按键映射后，应当进行测试。更改会在正常保存退出或本局结束时保存。


macro.txt 文件
==============

宏和按键映射保存在名为 macro.txt 的文件中；所在目录取决于平台和配置。可以在
初始化文件中用 macro_dir 选项指定该文件的读取和写入目录（详见
options_guide.txt）。macro.txt 是可直接阅读和编辑的文本文件，但非字母数字键
的键码可能需要通过游戏内试验或外部工具才能确定。

以 '#' 开头的行是注释，会被忽略。请注意，Crawl 把宏和按键映射保存到
macro.txt 时，不一定会保留你的注释。

每项宏定义恰好由两行组成。第一行描述触发宏的按键，由 "M:" 加上该键的字符或
键码构成（例如 'a'、'A' 或 \{9} 分别表示 A、Shift-A 或 Tab 键）。第二行描述
宏的动作，由 "A:" 加上要与上述按键关联的命令序列构成（例如 "za." 表示对瞄准
界面显示的默认目标施放法术栏 a 中的法术）。各项宏定义之间应以空行分隔。

对于按键映射，只需把定义第一行的 "M:" 替换为下列一项：
"K:"  默认，
"K1:" 楼层地图，
"K2:" 瞄准，或
"K3:" 确认。


示例
====

本节提供一些示例，帮助你了解宏和按键映射的用途。为求完整，示例同时给出按键
行和命令行；不过你很可能应该换成自己的按键，因为这些按键不一定适用于你的
系统。


在某些键盘布局上，'@' 字符默认可能无法使用。下面的映射把 '@' 映射到 '@'，
应能解决这个问题。

# @: 显示角色状态
K:\{17}
A:@


召唤师经常需要连续多次施放同一法术，而每次施法都要按好几个键，可能相当麻烦。
下面的宏可以用一次按键施放法术栏 'a' 中的法术。请注意，可以用 '=' 键重新
分配法术栏。再次强调，F1 键在你的系统上可能对应不同的键码。

# F1: 施放法术 'a'
M:\{368}
A:za


处理完召唤，我们还需要向召唤生物下达命令。下面的宏也能简化这项操作，并确认
瞄准界面显示的默认目标。

# Tab: 命令盟友攻击先前目标或最近目标
M:\{9}
A:ta.


咒法师施法需要稍有不同的宏，例如下面这个，因为他们必须按 '.' 或 Return 确认
向目标发射。此宏会确认瞄准界面显示的默认目标。

# F1: 对先前目标或最近目标施放法术 'a'
M:\{368}
A:za.


不过，即使是咒法师，也不一定总想攻击先前目标。因此，下面这组宏可以让他们
先施放法术栏 'a' 中的法术，再用同一个键循环切换可用目标，最后用前一个宏中
用于发射的同一个键确认。本例也试图说明：同一个按键在不同按键映射中可以具有
不同功能，善用这一点即可实现更灵活的操作。

# Shift-F1: 施放法术 'a'
M:\{1392}
A:za

# Shift-F1: 在瞄准模式中循环切换目标
K2:\{1392}
A:+

# F1: 在瞄准模式中向目标发射
K2:\{368}
A:.
