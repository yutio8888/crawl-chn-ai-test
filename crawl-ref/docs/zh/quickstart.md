Crawl 快速入门指南
==================

Copyright 1999 Linley Henzell


所以，你想跳过手册、马上开始玩 Crawl？请阅读这份指南，用最少的准备开始
Crawl 之旅。

我建议把它打印出来，在最初几局游戏中照着操作（游戏时也可以按两次 `?`
查看命令列表）。你还应该试试教程模式；它只需几分钟即可完成。

以后有空时，可以阅读 docs/ 目录下的 `crawl_manual.txt`，了解更详细的
信息。

CRAWL 简介
----------

Crawl 是一款规模庞大、随机性极强的地下探险游戏，背景是一个充满魔法与
频繁暴力冲突的奇幻世界。你的任务是深入每局都会变化的地牢，取回佐特宝珠。

Crawl 是 Rogue 后裔之一，属于 `rogue-like` 类型的角色扮演游戏。它的画面
简洁，却能提供丰富信息，力求让人一目了然；操作则主要通过单键命令完成。

开始游戏
--------

启动程序后，游戏会先询问你的名字。别在这里花太多时间，因为你的第一个角色
**不会**活得太久（抱歉，但事实如此）。

接下来会出现种族和背景选择菜单。山地矮人、牛头人或巨魔战士都是不错的选择。
精灵相当脆弱，人类各方面都很平庸，而较古怪的种族大多不适合新手。最后，你
可能还需要选择武器。我建议选斧（斧子很好玩）。

现在你已进入游戏。游戏画面分为三个部分：

 - 地图占据画面左上方。地图正中央的 `@` 符号（或玩家人物图块）代表你。
   地图上明亮的区域是你目前能看见的地方；以前到过、但当前看不见的地方会
   变暗。
 - 消息框是地图下方的大块区域。它会随时描述正在发生的事件，并不时向你
   提问。
 - 状态区（地图右侧）显示生命状况和能力等各种指标。

探索
----

试着四处走动，可以使用数字小键盘（分别试试开启和关闭 Num Lock），也可以
使用 Rogue 键（`hjklyubn`）。按 `o` 会启动自动探索，角色会一直移动，直到
看见敌人或发生其他值得注意的事件（例如发现一组楼梯）。

如果想知道画面上的某个字符代表什么，可以用 `x`（查看）命令获取简短描述，
再按 `v` 查看更多信息。使用 `O`、`C` 命令开门或关门，使用 `<`（上楼）和
`>`（下楼）命令走楼梯。

越往下走，地牢就越危险（但也越有趣！）。如果迷路，可以用 `X` 命令打开
当前整层的全屏地图。

物品
----

走上一阵后，你肯定会遇到一些散落的物品（也可能遇到怪物；若需要应对怪物的
帮助，请跳到“怪物”一节）。可以用 `g`（拾取）或 `,` 命令捡起物品，用
`d`（丢弃）命令再次丢下；`i`（物品栏）命令会显示你携带的东西。查看物品栏
时，按下任一物品对应的按键，可以查看更多信息和可用命令列表。

物品分为若干类型：

 - **武器**，用 `)` 符号表示。使用 `w`（持握）命令拿起武器。
 - **护甲**（`[`）。使用 `W`（穿戴）命令穿上或脱下护甲。较重的护甲能提供
   更多防护，但可能妨碍闪避、施法或使用远程武器。
 - **弹药**（用 `(` 符号表示）。使用 `f` 和 `F`（发射）投掷弹药。
 - **魔杖**（`/`）、**卷轴**（`?`）和**药水**（`!`）可能非常宝贵，但使用
   次数有限（每张卷轴和每瓶药水只能使用一次，每根魔杖也只有一定的充能次数）。
   用 e`V`oke 激活魔杖，用 `r`ead 阅读卷轴，用 `q`uaff 喝下药水。遗憾的是，
   起初你并不知道卷轴或药水有何作用，只能看到其外观描述。不过，一旦用过某种
   物品（例如治疗药水），今后你就能认出所有治疗药水。
 - **戒指**（`=`）和**项链**（`"`）会提供各种通常有益的效果。使用 `P`
   （戴上）装备它们，使用 `R` 取下。
 - **钱币**（`$`）可以在商店购买物品。

此外还有少数其他物品类型，你会在游戏过程中逐渐发现。

怪物
----

你也会碰到怪物（大多用英文字母表示）。尝试移动到怪物占据的格子即可攻击它。
按 Tab 会自动走向附近的怪物并发动攻击。

受伤时，你会损失生命值（显示在状态列表顶部附近）；生命值会随着时间推移，
通过自然恢复逐渐回升。生命值全部耗尽时，你就会死亡。

要生存下来，需要掌握几项基本战术：

 - 每次遭遇战后休息。`s`、`.`、Delete 或数字小键盘 5 会让你休息一回合；
   按 `5` 或 Shift 加数字小键盘 5 则会休息较长时间（完全恢复后会停止休息）。
 - 能避免时，绝不要同时与多个怪物战斗。始终退入走廊，迫使它们与你逐个交战。
 - 卷轴和药水等消耗品在你死后毫无用处，而且大多数消耗品在恶战刚开始时使用，
   比濒死时才用更有效。可以事先站在安全处，从一叠物品中“浪费”一个来尝试
   鉴定它们。
 - 记得在与怪物近身交战前先使用投射物。
 - 学会判断何时该逃离无法应付的敌人——这一点非常重要！跳过危险楼层往往是
   明智之举，但也不要做得太过头。

死亡
----

用不了多久，你很可能就会死去。

Crawl 中的死亡是永久的；你无法简单读取存档，从离开的地方重新开始。`S`
（保存）命令只用于让你中途离开游戏，之后再回来继续。退出（`Ctrl-Q`）则让你
放弃角色——如果你甚至懒得帮助其活着逃出去的话。

好了，快速入门指南到此结束。这些内容应该能帮助你度过最初几局，但 Crawl
极其复杂（有人会说复杂得过分），这么短的文档无法充分讲解。因此，当你准备好
开始接触魔法、技能与宗教信仰时，请翻阅完整手册。

祝你地牢探险愉快！
