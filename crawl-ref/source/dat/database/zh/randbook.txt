# randbook.txt: 随机神器书籍的关键词
#
# 本文件包含随机神器书籍的大部分关键词列表（及其权重）。
# 随机神器书籍有两种类型：
#  - 固定主题，变化等级（咒法、召唤/大地……）
#  - 固定等级，变化主题（等级 2 法术等）
#
# 书籍在 randbook.cc 中通过 build_themed_book() 以匹配其类型的法术填充。
#
# 主题书籍使用以下两种命名方案之一：
#   a) @book_name@ @<secondary school> adj@ @<primary school>@
#   b) @book_name@ @<primary school>@ and @<secondary school>@
#
# 或者，如果没有（明显的）次要学派，简单使用：
#   @book_name@ @<primary school>@
#
# 法术全部在某个等级范围内的书籍可能获得基于该范围难度的标题：
# "入门"（等级 1）、"简单"（等级 2-4）、"中等"（等级 4-6）、"困难"（等级 7-9）。
# @level@ 被解析为描述该书中最高等级法术的词。
#
# 书籍还可能获得先前的"拥有者"（或作者），可能是赐予的神祇（如果是礼物）、
# 本文件中定义的依赖学派的名称、随机名称，或适当的神祇（如果不是神赐礼物）。
# 依赖学派的名称包括与一个或多个学派有强关联的独特怪物或法术名。
# 深渊或地狱领主名称只能在"高级"书籍中使用（包含至少一个 6 级或以上法术）。
#
# 详细说明见主文件 randname.txt。
