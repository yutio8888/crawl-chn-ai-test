###############################################################################
# 随机神器名称
# -------------
# randname.txt: 查找随机神器类型
#
# 本文件包含随机神器类型的关键词列表（及其权重），
# 武器、护甲和饰品，以及与偶尔赠送随机神器的神祇组合，
# 即"特洛格 武器"、"奥卡瓦鲁 武器"、"奥卡瓦鲁 护甲"、
# "佐姆 武器"、"佐姆 护甲"和"佐姆 饰品"。
# 艾申扎利命名被诅咒的物品；这些名称不依赖类型，
# 在关键词"Ashenzari"下。文件末尾还有用于
# 未鉴定的随机神器外观的形容词列表。
#
# 关键词语法与怪物语音相同（详情见
# docs/develop/monster_speech.txt）。
# 任何被 '@' 符号包裹的短语都会被数据库识别为需要替换的关键词。
# 这些关键词的定义见以下文件：
#
#  o  rand_wpn.txt  - 主要用于武器的关键词
#  o  rand_arm.txt  - 主要用于护甲的关键词
#  o  rand_all.txt  - 用于饰品及所有三种类型的关键词
#  o  randbook.txt  - 用于随机神器书籍的关键词
#  o  硬编码（如 artefact.cc）
#
# 硬编码关键词列表：
#  * player_name     - 玩家角色名
#  * player_species  - 角色物种
#  * branch_name     - 随机爬行分支名
#  * god_name        - 随机爬行神祇名
#  * xom_name        - 佐姆的长名称之一
#
# 随机神器名称最多 25 个符号（含空格）。
# 此比较在所有替换完成后进行，
# 如果名称超过此限制，游戏将重新生成。
#
# 请注意，武器和护甲只有一半的随机神器使用数据库名称
# （另一半是完全随机的名称），饰品只有五分之一使用数据库名称。
# 这些几率是硬编码的。
#
# 祝你玩得开心！
