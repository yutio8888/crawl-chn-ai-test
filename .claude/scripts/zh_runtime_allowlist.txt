# abbreviations are matched case-insensitively; exact technical literals may
# also contain identifier, key, path, or URL punctuation and are matched
# case-sensitively as complete values with technical boundaries. Each value may
# appear embedded in Chinese translated text without triggering the MIXED_CN_EN
# rule (plan v2 §2.3 row 2; rule predicates live in
# catch2-tests/test_zh_helpers.cc:rule_mixed_cn_en).
#
# This is the manual portion. The auto-generated enum English-name portion
# lives in zh_runtime_allowlist_enum.txt; at runtime the helpers' built-in
# whitelist (in test_zh_helpers.cc) collates a generous default set that
# covers resistance/stat tags, canonical god names, dungeon/branch names,
# and tech prefixes (Tele, Rage, Highlight, ...).
#
# Add new entries below when a false positive shows up in a Layer 1 run.
# Each row has no surrounding whitespace. Standalone English tokens are
# matched case-insensitively; compound technical values are allowed only as
# exact, case-sensitive whole values and never as word fragments.
